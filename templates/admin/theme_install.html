Upload a theme (.zip)

The zip is extracted into the themes folder. It needs theme.py and index.html (a child theme only needs theme.py with THEME_PARENT). Maximum MB.

Create a child theme

A child theme inherits templates, layout and assets from its parent. Put a template with the same name in the child folder to override it, and add your own hooks in the child's theme.py. Updates to the parent never overwrite your changes.
